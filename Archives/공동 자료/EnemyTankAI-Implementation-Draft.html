1. 작동 원리와 실행 순서

적 전차는 지정된 경유점을 순찰하다가 플레이어 전차를 발견하면 교전한다. 시야를 잃으면 마지막으로 본 지점을 확인하고, 교전이 끝나면 저장해 둔 순찰 경유점으로 돌아간다. 상위 명령은 순찰과 교전을 중단하거나 목적지를 바꿀 수 있다.

Fusion 호스트가 TankAI.FixedUpdateNetwork()에서 권한과 생존 여부를 확인한 뒤 센서 갱신 → FSM 판단 → 이동·차체 입력 → 공격 또는 이동 중 조준 순서로 처리한다. 원격 클라이언트에서는 AI 판단을 실행하지 않고 기존 네트워크 방식으로 전차 상태와 행동 결과를 받는다.

구성 요소담당 동작
TankSensor · TankTarget전차별 진영·생존·식별 정보를 바탕으로 후보를 확인한다. 프리팹 기준 0.1초 간격으로 확인점을 검사한다. 새 표적은 40m · 120° 시야에 0.3초 확인되면 선택 후보가 되며, 선택 표적 유지 기준은 50m · 140°다. 목격 위치와 시각은 보이는 동안 갱신한다.
TankCombat순찰 경유점, 교전 중 표적과 버전, 교전 시작 위치, 마지막 목격 정보와 상태별 제한을 관리한다. StartPatrol, ForceMove, RetreatTo, CancelOrder를 상위 호출에 제공한다.
TankAI · TankPathNavMesh 경로를 계산하고 공용 주행을 실행한다. 포탑·포신 추적, 장전·발사 요청, 탄도상 첫 충돌 대상 확인을 맡는다. 차체와 무기 입력은 기존 전차 컴포넌트로 전달한다.

센서는 전차의 확인점이 보이는지를 보고, 무기는 현재 포신 위치에서 탄도가 해당 표적에 도달할지를 본다. 표적이 보여도 낮은 벽에 사선이 막힐 수 있다. FSM이 한 번 교전에 들어가면 대상의 개별 식별 정보를 유지하며, 가림 중에는 저장한 위치만 사용한다.

2. 전체 FSM

순찰은 목적 경유점을 유지한 채 교전이나 피격 확인에 들어간다. 복귀에 성공하면 해당 경유점으로 돌아온 뒤 다음 경유점으로 넘어간다. 강제 이동·퇴각·취소는 진행 중인 교전과 수색을 중단할 수 있다.

3. 교전 중 이동과 사격

사격 조건과 이동 중 추적

접근·위치 변경·근거리 후진 중에는 시야에 있는 표적의 조준점으로 포탑과 포신을 움직인다. 이때 새 장전과 발사 요청은 시작하지 않는다. 정지 사격에 들어가면 도착 상태 또는 차체 안정 조건을 확인한 뒤 공격을 요청한다. 무기 쪽에서 장전 상태, 포신 정렬, 발사 가능 상태와 탄도 예측을 모두 통과해야 발사가 요청된다.

사선이 막힐 때

탄도 예측의 첫 충돌이 다른 물체로 약 0.3초 이어지면 NavMesh에서 앞쪽 최대 5.5m, 좌우 4m 방향의 두 후보 중 조건을 만족하는 짧은 경로를 고른다. 후보는 발사 진입 거리 28m 안에 있어야 하고 경로는 교전 시작점 반경 35m 안에 있어야 한다. 예상 명중 자체가 없으면 차단 시간을 초기화한다.

위치 변경은 교전당 기본 한 번이다. 도착 전 표적이 8m 이내로 들어와 이동을 끊으면 사용 횟수를 한 번만 돌려준다. 8m 이내에서는 위치 변경을 요청하지 않는다. 8m 초과 12m 이하에서는 이격 시도와 위치 변경 중단 이력이 모두 없을 때만 위치 변경을 새로 판단한다.

표적이 가까이 붙을 때

8m 이내가 0.3초 지속되면 교전당 한 번 이격을 판단한다. 후진으로 거리가 벌어지는 방향인지, 뒤쪽 6m의 NavMesh 직선 구간과 차체 폭을 고려한 공간이 비어 있는지 확인한다. 시작 후에도 제동 여유 거리 안의 장애물을 확인한다. 표적 거리 12m, 후진 약 6m, 5초 제한, 1초간 진행 없음 또는 주행 실패 중 먼저 해당하는 조건에서 후진을 끝내고 정지 사격으로 돌아간다.

4. 상태별 Enter · Update · Exit

TankCombat.CombatState의 13개 상태를 기준으로 정리했다. Enter는 진입 시 준비, Update는 호스트 틱에서의 판단, Exit는 다른 상태로 넘어갈 때 수행하는 정리와 후속 전이를 뜻한다. 실제 코드는 Begin…, Update…, ChangeState와 전차 제어 메서드에 나눠 구현되어 있다.

상태EnterUpdateExit
대기
Idle		종료 사유를 남기고 FSM의 교전·순찰 상태를 정리한다.센서가 동작할 수 있어도 자율 교전과 순찰 판단은 대기한다.유효한 순찰 또는 이동·퇴각 명령을 받으면 해당 행동으로 전환한다.
순찰
Patrol		새 순찰은 NavMesh 모드와 첫 경유점을 지정한다. 복귀 직후에는 현재 경유점을 유지한다.현재 경유점으로 이동하고 도착하면 다음으로 넘긴다. 확인된 표적과 피격을 판단한다.표적 발견 시 같은 경유점을 보존하고 거리로 접근·정지 사격을 고른다. 표적이 안 보이는 상태에서 피격되면 주변 확인, 경로 실패 시 대기한다.
피격 후 주변 확인
CheckAfterHit		순찰 이동을 끊고 시작 방향을 기록한 뒤 왼쪽부터 차체를 회전한다.최대 3초간 좌우 약 45°를 확인한다. 추가 피격에도 제한 시간은 늘어나지 않는다.표적을 찾으면 회전을 끊고 교전한다. 확인을 마치면 기존 경유점으로 복귀한다.
접근
Approach		최대 8초를 타이머에 설정한다. 표적 앞 약 24m 지점과 좌우 후보를 비교해 유효한 NavMesh 경로를 선택한다.시야를 유지하며 이동·조준한다. 미도착 중 표적이 3m 이상 이동하면 0.5초 간격 제한 안에서 목적지를 다시 계획할 수 있다.이동 중 24m 이내 또는 도착 후 28m 이내면 정지 사격으로 전환한다. 경로·반경·시간 조건에 실패하면 정지하고 사유를 남긴다.
정지 사격
StopAndFire		도착 상태가 아니면 이동을 중단한다. 정지 조건을 확인하고 공격 요청을 준비한다.거리와 이격을 먼저 보고 이어서 사격이나 사선 차단을 판단한다. 32m 초과부터 공격을 멈추고, 그 거리가 0.5초 이어지면 재접근한다.재접근·위치 변경·이격·수색·복귀 전환 시 해당 이동 또는 정지 처리로 공격 요청을 정리한다. 거리 이탈 타이머를 초기화한다.
위치 변경
Reposition		좌우 후보 중 도달 가능한 위치로 이동을 요청한다. 시작에 성공하면 횟수를 올리고 최대 8초를 지정한다.표적을 조준하며 도착, 경로 상태, 35m 반경과 시간을 확인한다.도착하고 28m 안이면 정지 사격으로 돌아간다. 8m 이내로 붙으면 위치 변경을 끊고 정지 사격에서 이격을 판단한다. 경로·반경·시간·도착 거리 실패 시 복귀한다.
근거리 이격
BackOff		이격 시도 횟수를 먼저 사용한다. 후진 조건을 통과하면 공격을 취소하고 직선 후진을 시작한다.포탑·포신 추적을 유지하면서 거리, 실제 후진량, 진행 여부, 제동 범위 내 장애물을 확인한다.조건 충족이나 후방 차단 시 후진을 멈추고 사격을 다시 판단한다. 중단 사유와 실제 후진량을 기록한다. 상위 명령이나 시야 상실도 후진을 끊는다.
시야 상실 대기
WaitForSight		이동·공격을 끊고 마지막 목격 정보를 보존한다. 마지막 목격 시각부터 최대 10초의 수색 기한을 적용한다.0.75초간 동일 표적의 재발견을 확인한다.같은 표적이 보이면 현재 거리에서 교전한다. 계속 가려지면 마지막 목격 지점으로 이동을 시도하고, 기억 만료나 경로 실패 시 복귀한다.
목격 지점 이동
MoveToLastSeen		교전 시작점 반경 35m 안에서 마지막 목격 지점으로 가는 경로를 요청한다. 이동 단계 제한은 6초다.가려진 표적의 이동과 관계없이 기존 목적지를 향한다. 재발견, 도착, 경로·거리·시간 제한을 확인한다.도착하면 주변을 확인하고, 재발견하면 교전을 이어간다. 이동 실패 또는 수색 기한 만료 시 복귀한다.
주변 확인
CheckSurroundings		목격 지점에서 차체 이동을 정리하고 왼쪽부터 회전한다.좌우 약 45°를 확인한다. 회전 단계는 최대 3초이며 수색 전체 기한도 적용된다.같은 표적을 재발견하면 회전을 멈추고 교전한다. 회전 종료·실패 또는 기한 만료 시 복귀한다.
순찰 복귀
ReturnToPatrol		공격과 이동을 정리한 뒤 저장된 경유점으로 이동을 요청한다.기존 경유점까지의 도착 여부와 이동 실패를 확인한다.도착하면 교전 데이터를 정리하고 순찰을 이어간다. 복귀 경로가 없거나 실패하면 사유를 남기고 대기한다.
강제 이동
ForcedMove		기존 교전·수색을 정리하고 지정 좌표로 NavMesh 이동한다. 기존 순찰 정보가 있으면 보존한다.자율 교전 판단보다 현재 이동 명령을 우선한다. 도착·실패와 명령 교체를 확인한다.도착 후 보존된 경유점으로 복귀한다. 이어갈 순찰이 없거나 이동 실패·취소 시 대기한다.
퇴각
Retreat		교전을 끊고 호출자가 지정한 퇴각 좌표로 NavMesh 이동한다.표적이 다시 보여도 퇴각 명령을 수행한다. 새 명령이 접수되면 목적지를 바꿀 수 있다.도착·실패·취소 시 대기한다. 순찰 재개는 새 순찰 명령으로 요청한다.

5. 전이 우선순위와 실패 처리

  1. 자기 전차 파괴 또는 호스트 권한 종료. 이동·공격 요청과 FSM의 실행 상태를 정리한다.
  2. 새 이동·퇴각 명령 또는 취소. 이미 진행 중인 자율 동작을 끊는다. 강제 이동·퇴각을 수행 중이면 해당 명령의 도착과 실패를 먼저 처리한다.
  3. 교전 표적이 무효. 파괴·제거·버전 변경 등으로 표적을 추적할 수 없으면 시야 대기를 거치지 않고 순찰로 복귀한다.
  4. 유효한 표적을 시야에서 놓침. 이동·공격을 중단하고 마지막 목격 위치를 기준으로 수색한다.
  5. 표적이 계속 보임. 정지 사격에서는 거리 초과, 근거리 이격, 사선 차단 순서로 확인한다.
실패 상황전이와 처리시험
접근·재접근 경로 없음대기. 재접근을 포함해 접근 제한을 넘기거나 주행에 실패하면 정지하고 종료 사유를 남긴다.10, 31
목격 지점에 갈 수 없음순찰 복귀. 기억 만료, 반경 이탈, 시간 초과에도 같은 경유점으로 복귀한다.04, 12
위치 변경 후보 없음이동을 시작하지 않고 순찰로 복귀한다.16
위치 변경 중 실패경로 실패·반경 이탈·시간 초과를 기록하고 순찰로 복귀한다.17
옮긴 뒤에도 사선 차단기본 위치 변경 한도를 소진한 상태이면 순찰로 복귀한다.18
후방 경로 또는 장애물 문제시작 전이면 제자리 사격 판단을 유지한다. 후진 중이면 정지 사격으로 돌아간다. 이격 시도는 사용 처리된다.35, 36
복귀 경로도 실패이동과 공격을 정리하고 대기한다.05, 19

위치 변경에 실패한 대상은 순찰 복귀 뒤에도 계속 보이는 동안 재교전 후보에서 제외한다. 새 센서 검사에서 시야를 놓치면 제한이 풀려, 이후 재발견 시 다시 교전할 수 있다. 다른 유효한 표적은 순찰 중 새로 선택할 수 있다.

6. 검증 범위

2026-11-20 로컬 검증 기록에서 38/38 통과를 확인했다. Unity 6000.6.3f1의 TankAIIntegrationTest에서 로컬 Fusion 호스트, 시험용 전차, 실제 충돌체 및 NavMesh를 사용했다. 확인된 항목에는 접근·위치 변경 중 포탑 추적과 0발 유지, 정지 후 발사, 후진 중 장애물과 퇴각 명령 우선 처리가 포함된다.

카랑탕의 CarentanDrive는 기존 이동 시험에서 경유점마다 MoveTo를 호출한다. 실제 맵에는 TankCombat.StartPatrol 연결과 순찰·교전·복귀 검증이 남아 있다. 원격 클라이언트에서의 동작 재현은 별도 확인 범위다. 시험 버튼과 결과 파일은 TankAI.md에 정리했다.
