# TankTest 내부·외부 테스트 안내

> **2026-11-07 씬 분리 인계:** 현재 씬 구성·실행·연결 API·파트별 수정 위치는 [TankTest 씬 분리 인계 README](../../Docs/TankTest-SceneSplit-README.md)를 먼저 읽으세요. TankTest 단독 Play가 내부를 자동 로드합니다. 아래 내용은 이전 기능 개발 기록을 포함하며, 일부 역할·키 입력·Inspector 직접 연결·검증 설명은 현재 코드와 다릅니다. 현재 동작과 기존 제한은 새 인계 문서를 기준으로 확인하세요.

대상 씬: `Assets/TankPrototype/Scenes/TankTest.unity`

Play 후 Game 뷰를 클릭합니다. 기본은 **외부 테스트 모드**입니다.
**F8 = 외부, F9 = 내부**이며 같은 모드 키를 다시 눌러도 현재 상태를 유지합니다.
화면 위쪽 안내에서 현재 모드를 확인할 수 있습니다.

## 모드별 조작

| 키 / 동작 | F8 외부 테스트 | F9 내부 조작 |
| --- | --- | --- |
| 상단 1 / 2 / 3 | 테스트 역할: 조종수 / 포수 / 전차장 | 플레이어 좌석: 조종수 / 포수 / 전차장 |
| Space | 양쪽 주행 레버 중립 | 선택한 장치 조작 시작 / 종료 |
| Esc | 내부 동작 없음 | 장치 조작 종료, 조작 중이 아니면 시선 잠금 해제 |
| 마우스 | 전차장 관측에서 우클릭을 누른 채 회전 | 화면 클릭으로 시선 잠금, 마우스로 고개 회전 |
| 방향키 | 포수 포탑·포신 조준 | 조이스틱 사용 중 포탑·포신 조준 |
| 마우스 휠 | 포수 확대·축소 입력 없음 | 조이스틱 사용 중 위로 확대 / 아래로 축소 |
| F3 | 전차장 관측 | 외부 카메라 입력 차단 |
| F4 | 외부 3인칭 | 외부 카메라 입력 차단 |
| F6 | 내부 디버그 입력 차단 | 장치 판정 디버그 표시 전환 |
| F7 | 내부 디버그 입력 차단 | 플레이어 뒤 관찰 / 1인칭 전환 |

외부의 기존 테스트 조작:

- W/S: 왼쪽 레버 증가/감소, I/K: 오른쪽 레버 증가/감소.
- Q/U: 왼쪽/오른쪽 레버 중립. 키를 떼면 레버 값은 유지됩니다.
- 숫자패드 1~6: 기존 주행 프리셋.
- 방향키: 포탑·포신 조준.
- R → T → Enter: 삽입 → 폐쇄 → 사격. Y: 빈 약실 열기.
- 역할 권한은 그대로 적용됩니다. 이동은 조종수, 조준·사격은 포수입니다.

## 전환할 때의 상태

- 전환 직후에는 누르고 있던 키와 마우스 버튼을 모두 뗀 뒤 새로 누릅니다. 전환한 같은 프레임의 숫자키·Space도 새 모드로 전달하지 않습니다.
- 내부 좌석·역할과 외부 테스트 역할은 각각 유지하며 서로 복사하지 않습니다.
- 외부로 나갈 때 내부 장치 사용·선택·흰 테두리와 F7 관찰을 종료하고 커서 잠금을 해제합니다.
- F8은 외부 3인칭으로, F9는 마지막 내부 좌석의 1인칭으로 진입합니다. F7은 다시 눌러 사용합니다.
- 레버 값, 탱크 이동 물리, 무기 회복은 유지됩니다. 모드 전환은 정지 명령이 아닙니다. 필요하면 외부 조종수 역할에서 Space로 중립을 지정합니다.
- 창 포커스를 잃으면 입력을 차단합니다. 복귀 후 키·버튼을 놓아야 다시 입력을 받습니다.

## 내부 상호작용과 F7

담당 좌석에서 장치를 화면 중앙으로 바라보면 흰 테두리와 Space 안내가 표시됩니다.
등록된 `CrewDevice`와 `InteriorDevice` 레이어, 담당 역할, 거리, 벽 가림 조건을 모두 만족해야 선택됩니다.
두 레버는 하나의 주행 장치이며 잠망경 화면·지도·조준경·조이스틱·폐쇄기·개별 포탄도 기존 등록을 유지합니다.

F7은 좌석에 앉은 몸 뒤에서 플레이어를 관찰합니다. 마우스는 플레이어의 시선을 회전시키며, 관찰 카메라는 몸 뒤에 머뭅니다.
시야선과 중앙 선택·유지 범위는 플레이어 눈 카메라를 기준으로 그립니다. F6으로 디버그 표시를 끌 수 있습니다.

현재 장치의 공통 선택·사용 상태까지 구현되어 있습니다. 내부 주행 장치 사용을 실제 `TankControl` 주행 명령으로 연결하는 작업은 별도입니다.
F8은 개발용 외부 테스트이며, 플레이어가 실제로 전차 밖으로 나가는 기능은 포함하지 않습니다.

## 씬 연결과 코드 담당

`LocalTestMode` 오브젝트의 `TankTestMode`가 로컬 모드의 원본입니다.
`Start Mode`를 Inspector에서 바꾸면 시작 모드를 변경할 수 있습니다.

| 연결 | 대상 / 담당 |
| --- | --- |
| Tank Input | TigerTank의 기존 `TankInput` |
| Tank Cameras | TigerTank의 `TankCrewCameras` |
| Tank Hud | TigerTank의 `TankKeyboardDebug` |
| Look / Interaction / Debug View | Rooms/LowerRoom/CrewPlayer의 해당 컴포넌트 |
| Interior Hud | 씬 루트의 InteractionHUD |
| Mode Label | LocalTestMode/ModeHUD/ModeLabel의 Text |

`TankInput`, `CrewSeats`, `CrewLook`, `CrewInteract`, `CrewDebugView`의 `Test Mode`도 동일한 컴포넌트에 연결합니다.
모드 참조가 없는 기존 tankroom 씬과 단독 탱크 프리팹은 기존 입력 방식을 유지합니다.

- `TankTestMode`: F8/F9, 입력 재허용 시점, 출력 담당 전환, HUD 전환.
- 각 입력 컴포넌트: 자신의 입력을 읽기 전에 해당 모드의 허용 여부 확인.
- `CrewSeats`: 컴포넌트를 끄지 않아 좌석 상태와 기존 승인 API 유지.
- `TankCrewCameras.SetOutput`: 외부 화면·오디오 출력 허용. 내부 모드에서는 외부 시점 API가 호출되어도 화면을 켜지 않음.
- `CrewDebugView.SetOutput`: 내부 1인칭·F7 관찰 화면·오디오 출력 허용.

화면용 Camera와 AudioListener는 각각 하나만 켭니다. RenderTexture용 카메라는 별도로 구성합니다.
고정 UI와 참조는 씬에 저장되어 있으며 실행 중 생성하지 않습니다.
포수 입력은 `TankControl`에서 장치 사용자를 확인한 뒤 `TankAim`과 `GunnerSight`에 전달합니다.

## 전차장 관측 장비

F9 내부 모드에서 상단 3으로 전차장 좌석에 앉고 `Rooms/UpperRoom/scope (1)`을 바라본 뒤 Space를 누릅니다.
기존 F3의 `Commander Camera`가 전체 화면을 담당하며, RenderTexture를 사용하지 않습니다.
내부 모드·좌석·고개 방향은 유지됩니다.

우클릭을 누른 채 마우스를 움직이면 관측 카메라만 회전합니다. 첫 커서 잠금 프레임의 이동은 무시하며,
우클릭을 놓으면 마지막 관측 방향을 유지합니다. Space / Esc로 사용을 종료하면 진입 전 내부 시점과 시선 제어로 복귀합니다.
F7에서 진입했다면 해당 관찰 시점도 복원합니다.

관측 중에는 내부 고개 회전·장치 선택 HUD·F7 입력을 중단합니다. 포수·조종수 관측 영상은 유지합니다.
좌석 변경, F8 모드 전환, 포커스 상실, 장치·입력·카메라 제어의 비활성화도 관측을 종료합니다.
`LocalTestMode`의 `Commander Sight` 필드가 기존 장치와 연결되어 있습니다.

2026-11-04 Play Mode의 가상 키보드·마우스 입력으로 진입·회전·Space/Esc 복귀,
좌석·모드 전환과 비활성화, F7 복원, 카메라·오디오 단일 출력을 확인했습니다.
반복 관측 회전 API는 워밍업 후 1,000회에서 관리 메모리 할당 0바이트였습니다.
결과·검증 범위·화면은 `Builds/CommanderSight-2026-11-04/`에 보관합니다.
OS 창 포커스 전환과 물리 마우스의 조작감은 직접 Game 뷰에서 확인합니다.

## 포수 관측창

`Rooms/UpperRoom/sight/screen`은 기존 포수 카메라의 영상을 상시 표시합니다.
F9로 내부에 진입한 뒤 상단 2로 포수 좌석에 앉아 관측창을 바라봅니다. Space로 장치를 사용하지 않아도 영상은 표시됩니다.

기존 `TigerTank/tiger-body/tiger-turret/Gun Pitch Pivot/Gunner Camera`가
`GunnerView` RenderTexture에 출력하고, 화면의 `GunnerScreen` 재질이 그 영상을 표시합니다.
카메라는 기존 조준 피벗 아래에 있어 포탑·포신 방향을 따릅니다. F2 전체 화면 관측은 사용하지 않습니다.

`sight`의 `GunnerSight`가 카메라와 화면의 활성화를 담당합니다.
화면 출력 전환과 독립적으로 영상을 유지하며, 이 컴포넌트를 끄면 촬영과 표시를 함께 중단합니다.
카메라·RenderTexture·재질·화면 참조는 씬에 저장되어 있습니다.

포수 좌석에서 조이스틱을 바라보고 Space로 사용을 시작합니다.
사용 중 방향키 좌우는 포탑, 상하는 포신을 조준하며 마우스 휠은 관측 카메라를 확대·축소합니다.
조작을 시작한 뒤 관측창을 바라봐도 조이스틱 사용은 유지됩니다.

방향키를 놓으면 회전이 멈추고 조준 각도는 유지됩니다. Space / Esc로 사용을 종료하거나
좌석·내부/외부 모드를 바꾸거나 창 포커스를 잃으면 조이스틱 사용과 조준 입력을 해제합니다.
장치를 사용하지 않을 때는 내부 방향키·휠 입력이 조준과 배율을 바꾸지 않습니다.

FOV는 기본 55도, 범위 15~55도, 휠 한 칸당 5도입니다.
`sight`의 `GunnerSight`에서 Min Fov / Max Fov / Zoom Step을 조정합니다.
배율은 사용을 종료해도 유지되며, 확대는 플레이어 눈 카메라와 실제 조준 각도에 영향을 주지 않습니다.
손 IK와 조이스틱 손잡이 애니메이션은 이 입력 연결에 포함하지 않습니다.

2026-11-04 Play Mode에서 실제 영상 출력·조준 피벗 추종, 관측창 활성화/비활성화,
내부·외부 반복 전환과 씬 재진입을 확인했습니다. 직접 화면용 카메라·AudioListener는 각각 하나이며,
조종수 영상도 유지됩니다. 검증 결과와 화면은 `Builds/GunnerScreen-2026-11-04/`에 보관합니다.

같은 날 내부 조이스틱의 가상 방향키·휠 입력, 미사용/역할 검사, Space·Esc 종료,
좌석·모드 전환, 포커스 상실과 비활성화 처리까지 Play Mode에서 확인했습니다.
검증 경로의 반복 입력·조준·줌 호출은 워밍업 후 관리 메모리 할당 0바이트였습니다.
결과·측정 범위·화면은 `Builds/GunnerInput-2026-11-04/`에 보관합니다.

## 검증과 수동 확인

검증 결과는 프로젝트 루트 `TestResults/ModeSwitch-2026-10-31/`에 기록합니다.
2026-10-31 기준 가상 입력을 사용한 Play Mode 검사 215개를 통과했습니다.
Play Mode 검증에서는 세션 접속만 일시 차단하고 탱크 입력·카메라·내부 시스템을 함께 실행합니다.
검증 후 저장된 씬을 다시 열어 원래 NetworkAsset 상태를 복원합니다.

직접 확인할 순서:

1. Play 후 F8: 외부 화면 하나와 외부 HUD가 나오는지 확인합니다.
2. 1/2/3을 눌러도 내부 플레이어 좌석은 바뀌지 않는지 확인합니다.
3. F9 후 키를 놓고 1/2/3: 각 좌석으로 이동하는지 확인합니다.
4. 담당 장치를 바라보고 Space: 흰 테두리·사용 시작/종료를 확인합니다.
5. F7 후 마우스로 고개를 돌려 눈의 시야와 중앙 판정 범위가 움직이는지 확인합니다.
6. 장치 사용·F7 상태에서 F8: 내부 조작과 관찰 화면이 종료되는지 확인합니다.
7. F9: 마지막 좌석의 1인칭으로 돌아오는지 확인합니다.

물리 키보드·마우스의 감각, 커서 잠금과 화면 가독성은 실제 Game 뷰에서 최종 확인합니다.
네트워크 동기화와 VR 입력 검증은 포함하지 않습니다.
