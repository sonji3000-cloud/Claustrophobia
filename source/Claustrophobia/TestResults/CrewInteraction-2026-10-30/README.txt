사용 방법
- Game 화면 클릭: 기존 1인칭 마우스 시점 시작.
- 1 / 2 / 3: 조종수 / 포수 / 전차장 좌석 이동.
- 중앙의 점으로 장치를 바라보면 선택된 장치 하나에 얇은 흰 테두리와 안내 표시.
- Space: 선택된 장치 조작 시작, 다시 누르면 종료. 누르고 있으면 반복 전환하지 않음.
- 조작 중 고개를 돌려도 같은 장치를 유지. 다른 장치는 종료 후 선택.
- Esc: 조작 중이면 우선 조작 종료. 그 외에는 기존 커서 해제.
- F6: 중앙 선택 원, 선택 유지 여유 원, 실제 후보 지점, 장치별 판정 사유 표시.
- F7: 내부 관찰 카메라. 우클릭 드래그로 회전, 휠로 거리 조절, F7로 복귀.
- 관찰 중에도 판정 기준은 1인칭 카메라. 플레이어 시선/좌석 키/Space 조작은 일시 정지.
- 관찰 복귀 후 시점 조작은 Game 화면을 다시 클릭하면 시작.
- Scene 뷰에서 CrewPlayer 선택: 장치 선택 영역의 경계와 실제 판정 지점 Gizmo.

선택 규칙
- 현재 역할에서 사용 가능한 활성 장치만 후보로 둠.
- 기본 거리 2m, 중앙 원 반지름은 카메라 화면 높이의 5%.
- 중앙 광선이 직접 맞는 장치 우선. 그 외에는 실제 표면 샘플의 화면 중심 거리를 비교.
- 화면 중심 거리가 거의 같을 때 실제 표면까지의 거리를 비교.
- 기존 선택은 1.3배 범위까지 유지하며, 직접 맞는 다른 장치에는 즉시 양보.
- 각 선택 지점으로 물리 광선을 보내 가장 먼저 맞는 충돌체를 확인. 벽 뒤 후보는 제외.
- 표면 검사는 중앙 방향/중심/안쪽 모서리 총 10개 방향을 이용한 근사이며,
  복잡한 메시의 모든 보이는 픽셀을 검색하는 방식은 아님.
- reach / radius / retainScale / blockers는 CrewInteract Inspector에서 조절.

장치 구성
- TankInterior/Devices/DriveDevice 아래 기존 두 lever 모델을 함께 배치.
- 각 모델의 실제 메시 충돌체 총 4개를 하나의 CrewDevice에 연결.
- 어느 레버를 선택해도 Drive controls로 진입하고 양쪽 레버의 테두리가 함께 켜짐.
- 기존 조준경 두 개, joystick, breech_block에도 공통 컴포넌트를 연결.
  역할은 조종수=주행, 포수=포수 조준경/조이스틱/포미, 전차장=전차장 조준경/포미.
- 포미 허용 역할은 장치 자체에 명시. 기존 TankCrew.CanLoad에는 의존하지 않음.
- 기존 모델 배치는 그대로이며, 기본 거리 밖에 놓인 장치는 가까운 표면을 바라봐도
  범위 안에 들어와야 선택됨. 실제 장치별 배치/접근성 조정은 후속 작업.
- 현재 씬에 지도 모델은 없음. 지도 조작이나 가상 지도 장치를 새로 만들지 않음.

코드 책임
- CrewDevice: 장치 이름, 역할, 여러 선택 부위, 흰 테두리, 로컬 사용 상태.
- CrewInteract: 중앙 선택, 재검증, Space 조작 전환, 시작/종료 통지.
- CrewInteractHud: 씬에 저장된 UI 갱신. 진단은 실제 Candidate 판정 결과 사용.
- CrewDebugView: 별도로 저장된 관찰 카메라와 시야/중앙 범위 선 갱신.
- CrewLook: 조작 중 Esc가 커서 해제까지 함께 실행되지 않도록 기존 처리 보완.
- CrewSeats: 관찰 중 좌석 키 입력 일시 정지. 좌석 적용 이벤트에서 장치 조작 종료.
- 선택/조작 상태만 구현. 주행, 조준, 사격, 장전, 지도 동작은 아직 연결하지 않음.
  실제 기능은 Active와 UseChanged(device, active)를 이용해 해당 장치에 연결할 수 있음.
- 시작/종료 통지는 플레이어 Active와 장치 User 상태가 변경된 뒤 발생.
- 장치 조작 종료는 탱크 레버 값을 중립으로 바꾸지 않음. 이번 단계는 탱크 상태를 쓰지 않음.

네트워크 경계
- NetworkRunner, SessionJoinInit, RPC, 동기화, 점유 승인 코드는 수정하지 않음.
- CrewDevice.User는 현재 실행 환경 안의 로컬 사용 상태이며 네트워크 권한이 아님.
- TryUse(device)는 현재 선택/역할/가림을 다시 검증하는 로컬 진입 API.
  향후 담당자가 권한/점유 승인 및 해제를 연결해야 함. 원격 호출을 직접 허용하지 않음.
- 외부 전차 테스트의 TankInput.Space 양쪽 중립 기능은 이번 작업에서 변경하지 않음.
  내부/외부 입력을 실제 연결할 때 Space 중복 처리 제거와 중립 키 재배치 필요.
- TankCrew / TankControl / TankInput / TankMotor 기존 코드는 변경하지 않음.
