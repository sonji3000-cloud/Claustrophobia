TankTest F8 외부 / F9 내부 입력·카메라 전환 검증
2026-10-31 / Unity 6000.6.3f1

대상: Assets/TankPrototype/Scenes/TankTest.unity
사용 안내: Assets/TankPrototype/README.md

구현 결과
- LocalTestMode와 안내 Canvas/Text를 씬에 직접 배치하고 참조를 저장했다.
- F8은 기존 TankInput 외부 테스트, F9는 내부 좌석·장치 입력으로 구분한다.
- 외부 진입은 3인칭, 내부 진입은 마지막 좌석의 1인칭이다.
- 내부·외부 역할은 별개로 유지한다. 모드를 바꿀 때 레버 값은 유지한다.
- 장치 사용·선택·외곽선과 F7 관찰은 외부 전환 시 종료한다.
- 전환 프레임과 누른 채 넘어온 키·마우스 버튼은 차단하며 놓은 뒤 재입력한다.
- 내부/외부 카메라 소유자가 출력 허용 상태를 적용해 화면 중복을 방지한다.
- TankControl, TankMotor, TankAim, TankGun, TankCrew, TankKeyboardDebug 및 네트워크 코드는 수정하지 않았다.
- 원본 방·플레이어 프리팹을 수정하지 않았다. 새 연결은 TankTest 씬의 인스턴스에 저장했다.

Play Mode: 215개 검사 통과 (results.json)
- 실제 Play Mode에서 가상 Keyboard/Mouse를 만들고 기존 입력 판독 메서드를 호출했다.
  창 포커스와 물리 커서 조작 없이 판독 결과를 확인하기 위한 방식이다.
  모드 전환 사이에는 실제 프레임이 진행되도록 기다렸다.
- 외부 1/2/3은 탱크 테스트 역할만, 내부 1/2/3은 좌석만 변경했다.
- F8/F9와 동시에 누른 Space·숫자키와 계속 누른 키는 새 모드로 전달되지 않았다.
- 내부 Space는 장치 사용만 시작·종료했고 외부 레버를 중립으로 만들지 않았다.
- 외부 Space는 기존 조종수 중립 명령을 수행했다.
- 20개 장치 / 담당 좌석별 33개 조합의 거리 내 가시 표면, 선택·등록 외곽선·HUD·Space 시작/종료를 확인했다.
- InteriorDevice 레이어, 역할 제한, 임시 벽으로 가린 경우 선택 차단을 확인했다.
- F7 뒤 관찰, 눈의 마우스 회전과 고정된 몸 뒤 카메라, 시야선·선택/유지 범위, 1인칭 복귀를 확인했다.
- 장치 사용·F7 상태에서 F8 전환 시 사용 해제·선택 해제·카메라 복귀를 확인했다.
- 외부 카메라 API를 내부 모드에서 호출해도 외부 화면이 켜지지 않았다.
- 검사한 모드·시점 전환 지점에서 화면 카메라와 AudioListener가 각각 1개였고 Camera.main도 일치했다.
- 물리·TankControl은 계속 활성 상태였다.

반복 경로 측정
- 캐시한 델리게이트로 입력 판독·장치 선택을 워밍업 후 200회 호출했다.
- 같은 스레드의 관리 메모리 할당 증가 0바이트, 총 19.4863ms였다.
- Editor 직접 호출 측정이며 전체 프레임/Player 빌드 Profiler GC.Alloc 측정이나 성능 보장은 아니다.
