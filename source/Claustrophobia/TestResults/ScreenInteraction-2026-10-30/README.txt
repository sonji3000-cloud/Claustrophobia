InteriorDevice 선택 필터와 화면 상호작용 — 2026-10-30

씬: Assets/Scenes/tankroom.unity
Unity: 6000.6.3f1

연결
- DriverViewScreen: 조종수 잠망경 화면. 조종수 역할에서 선택/Space 조작 시작·종료.
- DriverMap: 조종수 지도. 조종수 역할에서 선택/Space 조작 시작·종료.
- CommanderMap: 전차장 지도. 전차장 역할에서 선택/Space 조작 시작·종료.
- 화면을 중앙으로 바라보면 얇은 흰 테두리와 대상 이름/Space 안내 표시.
- 기존 5개 장치에 세 화면을 추가해 등록 장치는 총 8개.
- 기존 위치·회전·크기·원본 재질은 보존(configuration.json).
- 실제 잠망경 영상 출력 및 지도 콘텐츠/확대 조작은 후속 기능.

판정
- CrewInteract의 targets를 InteriorDevice(8번 Layer) 하나로 저장.
- 등록된 장치의 루트와 유효한 선택 충돌체가 해당 Layer에 속해야 선택 가능.
- 중앙 직접 적중과 중앙 주변 표면 검사 모두 Layer 필터 적용.
- 벽 가림 검사는 별도 blockers 마스크로 유지. Default 벽도 대상을 차단.
- Layer는 후보 필터이며 Layer 지정만으로 새 물체의 행동이 자동 생성되지는 않음.
  새 장치는 CrewDevice/선택 충돌체/테두리/등록 목록을 편집기에 연결해야 함.
- 포탄 등 나머지 Layer 물체에 새로운 동작/충돌체를 이번에 추가하지 않음.
- 반복 경로에서 전체 씬 검색, 문자열 Layer 조회, 배열/LINQ 생성 없음.

거리 설정
- 기존 장치는 플레이어 기본 2m 유지.
- 세 화면은 현재 확인된 배치가 좌석에서 2m를 넘으므로 장치별 8m 선택 거리 저장.
- CrewDevice.reach가 0이면 플레이어 기본값, 양수이면 장치별 거리 사용.
- 이 값은 nonVR 카메라 선택 거리. 향후 VR 손의 직접 접촉/잡기 범위와는 별도.
- 디버그 시야선의 길이는 선택/사용 장치의 거리를 반영.

검증
- 실제 씬에서 Play Mode 검사 29개 통과(results.json).
- 세 화면을 담당 좌석에서 선택하고 테두리 표시/Space 시작/누름 유지/종료 확인.
- Default Layer로 변경 시 선택·진입 제외, 복구 시 재선택 확인.
- 별도 Default 벽을 앞에 두면 차단되는지 확인. 검사 벽은 종료 전에 삭제.
- 사용 중 Layer가 바뀌면 조작 종료, 역할 제한, 레버 선택, F7 기준 유지 확인.
- warmed RefreshSelection 1,000회에서 Editor 호출 스레드 관리 할당 0바이트.
  전체 씬/Player/UI가 GC.Alloc 0이라는 의미는 아님.
- 세 화면 캡처를 열어 테두리와 안내 문구 확인.
- 입력 검사는 가상 키보드를 실제 ReadKeys 처리기에 전달한 결과.
  OS 포커스/커서 입력을 가져오지 않았으며 실제 키보드·포커스 경로는 수동 확인 필요.
- 임시 편집기 도구 제거 후 최종 컴파일 확인(compile.json).
